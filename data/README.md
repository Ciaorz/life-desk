## 封面图片

- 命名规则：`类目-编号.jpg`，编号**全局递增**（不重复）
- 例：`去过的地方-0001.jpg`、`想去的地方-0002.jpg`
- 看编号就知道传到几号，补传时从下一个号开始，已传过的不用重复传

> ✅ 你原来贴的 Google 图片外链（`encrypted-tbn0.gstatic.com`）
> **已经成功下载并保存到本地**了，手机端现在可以正常显示。
> 不过外链有失效风险，之后录新的建议直接用表单里的「上传」按钮选本地图片。

## 手动上传到 GitHub（不用 Token）

1. 打开仓库，进入要存放数据的目录（例如 `data/`）
2. 点右上角的 **Add file → Upload files**
3. 从**本文件夹**把文件拖进去：
   - `lifedesk.json`（主索引，有变动就要传）
   - 各个 `{类目}-data.json`
   - `images/` 下的封面（只传新增编号的）
4. 点 **Commit changes**

> 也可以把本目录当 git 仓库：`git add . && git commit && git push`，一次推完更快。

## 手机端查看

手机端打开站点后直接读仓库里的静态文件（不需要 Token）。
看不到最新内容时，确认 `lifedesk.json` 和对应类目文件都已上传，再刷新页面。
