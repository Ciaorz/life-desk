如果没通过

    
    
      
  1. ① 失败 → 项目没部署成功，或地址打错了。回 Cloudflare 看部署日志。
    2. 
      
  2. ② 显示 401 → 令牌不对。检查 Settings → Variables and Secrets 里
        SYNC_TOKEN 的值，注意前后不要有空格。
    3. 
      
  3. ② 显示 500 或 DB is not defined → D1 绑定没加，或名字不是大写的
        DB。加完绑定必须 重新部署一次才生效。
    4. 
      
  4. ② 显示 no such table: records → 建表 SQL 没执行，
        去 D1 Console 里跑一遍 cloud/schema.sql。
    5. 
      
  5. ③ 显示 404 → 这个接口是后加的，说明项目还没 重新部署。
        把 cloud/pages-upload/ 里那两个文件再拖一次即可。
    6. 
      
  6. ③ 查得到书名、但封面裂了 → /api/isbn-cover 的转发有问题，
        回 Cloudflare 看那次请求的状态码。
    7.
